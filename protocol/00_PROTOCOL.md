# Frozen protocol

The study compares **Direct** versus **AI-Native Workflow** while keeping task information and available resources matched.

- T1–T4: execution-only. No external literature research. Two fixed ecosystems are run independently.
- T5–T7: research/reproduction tier. Main may route among the identical permitted model/tool pool in both conditions.
- T5–T7 include matched normal and Main-state-loss runs. T3/T4 state-loss mirrors are optional.
- Scoring is continuous wherever possible and preserves each benchmark's native metric.
- No scored rerun is permitted because a result is poor. Infrastructure failures must be classified and retained.
