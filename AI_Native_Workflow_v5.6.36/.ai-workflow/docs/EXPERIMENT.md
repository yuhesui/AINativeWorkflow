# EXPERIMENT.md — Experiment Workstream Guide

Experiment is a specialist chat/reasoning workstream activated by Main when empirical methodology or interpretation materially affects the Phase.

Experiment owns estimands, controls, benchmark design, frozen protocols, data/seed namespaces, statistical units, analysis plans, evidence ceilings, and interpretation. It may delegate implementation and runs through the coding-agent Orchestrator but should not silently revise a frozen protocol after observing results.

Separate screening, development, pilot, locked, and verified evidence. Failed runs remain visible. Return a runnable contract and interpretation map to Main.
