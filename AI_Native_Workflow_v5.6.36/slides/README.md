## Concept

**Verification as execution control for long-horizon agents.**

The educational resource teaches a general concept: verification should not merely score a finished agent output; it can control where an agent resumes, what evidence remains valid, and when authority must return upward. AI-Native Workflow supplies one concrete, runnable example rather than serving as the sole subject of the lesson.
