## Concept

**AI Native Workflow for Research: formalizing the informal AI workflows researchers already use.**

The resource begins from a realistic baseline - researchers may already use persistent chat for planning, a research agent for literature, and a coding agent for implementation. It then shows how durable intent/state/evidence, hierarchical Phase planning, DIC/EPS separation, coding-agent orchestration, parallel subagents, verification, and escalation can make that workflow more coherent and more autonomous without consuming proportionally more human supervisory attention.

The educational target is not "replace the researcher" or "save time at all costs." It is to **reduce coordination attention and preserve scientific attention**.
