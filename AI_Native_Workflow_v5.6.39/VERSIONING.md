# Versioning — AI Native Workflow

Current release: **5.6.39**.

The project remains on the 5.6 line while changes preserve the same core identity: repository-backed long-horizon execution with explicit hierarchy, durable contracts, bounded machine execution, evidence, recovery, and human authority.

## Minor version updates

A 5.6.x increment may change:

- runtime schema details;
- documentation structure;
- role wording;
- prompt guidance;
- tracking structure;
- tests / validation;
- submission or Education material;
- compatible DIC/EPS fields.

## Major architecture change

A future major line should be considered when the canonical hierarchy, authority model, DIC semantics, or runtime boundary changes incompatibly.

## Naming convention

Proper framework name: **AI Native Workflow**.

Generic adjective: **AI-native**, e.g. “an AI-native research workflow.”

Package filenames may continue to use `AI_Native_Workflow_*`. Runtime directory remains `.ai-workflow/`.

## History

Use root `CHANGELOG.md` for the cumulative history. Detailed superseded changelogs remain under `history/changelogs/`.
