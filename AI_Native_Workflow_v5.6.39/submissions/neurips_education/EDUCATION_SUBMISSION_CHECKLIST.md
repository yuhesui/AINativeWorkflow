# NeurIPS 2026 Education Track - Preparation Checklist

## Concept and pedagogy

- [x] One coherent concept is identified: **AI Native Workflow for Research**.
- [x] Starts from an informal workflow many researchers already use (planning chat -> research -> coding agent -> analysis/writing) rather than a no-workflow straw man.
- [x] Shows how the workflow can be adopted wholesale, adapted, or used to strengthen an existing practice.
- [x] Hierarchical planning is taught as an enabling mechanism available with current AI surfaces, not claimed as a new idea by itself.
- [x] Human-attention objective is explicit: reduce routine coordination/reconstruction attention per unit of verified progress while preserving scientific judgement.
- [x] DIC is taught as both durable contract and human-intelligibility/compression interface.
- [x] Constraint-objective inversion/defensive drift and salience flattening are presented as workflow failure modes, not universal empirical LLM properties.
- [x] Audience and prerequisite level are stated.
- [x] Learning objectives include understanding, applying, analysing, and adapting the workflow to a learner's own project.
- [x] Human examples, a learner exercise, instructor solution, and limitations are planned.
- [x] Recent frontier papers are mapped to the relevant mechanisms.

## Submission components

- [ ] No-more-than-two-page PDF compiled in the official `education, final` template without checklist.
- [ ] Authors included for single-blind review.
- [ ] Original teaching-materials ZIP below 200 MB.
- [ ] Final source slide deck and rendered PDF.
- [ ] Accessibility/alt-text review complete.
- [ ] License and permanent resource links complete.
- [ ] OpenReview upload performed by the human author.

## Integrity

- [x] Human-attention efficiency is an evaluation target, not a completed empirical claim.
- [x] Deterministic runtime evidence is labelled structural/demo evidence.
- [x] Package recovery is not described as semantic correctness.
- [x] Planned comparative experiments are not reported as completed.
- [x] AI Native Workflow is taught as an adaptable research workflow, not as a claim that every researcher must use the exact implementation.
