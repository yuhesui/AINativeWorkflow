## Failure representation

A request may end `complete`, `partial`, `blocked`, `negative-result`, `superseded`, or `abandoned`. Do not force unsupported success.


## Salience rule

At least one request must be explicitly primary. Supporting and optional requests must state how they strengthen the Primary Aim; otherwise defer or remove them.
