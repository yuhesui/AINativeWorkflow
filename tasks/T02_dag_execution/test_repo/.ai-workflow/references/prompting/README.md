# Official prompting/context guidance provenance

The runtime contains synthesized operational guidance in `docs/PROMPTING_CORE.md`, `docs/CODEX_EXECUTION.md`, `docs/CLAUDE_EXECUTION.md`, and `docs/GPT56_ROUTING.md`.

This directory records the official provider sources used to audit those summaries. It intentionally stores source metadata/links rather than republishing full provider webpages. Exact access should be refreshed during experiment setup and the returned content hash/archival metadata recorded in `SOURCE_LOCK.json`.
