# THEORY.md — Theory Workstream Guide

Theory owns formal reasoning, conceptual analysis, literature/novelty, propositions, counterexamples and claim classification.

Use `DIC/PLAN.md` to coordinate derivation, hostile attack, primary-literature search and reconciliation prompts. Parallelize genuinely independent positive/negative/novelty branches and merge explicitly. Useful custom DIC views include `THEOREM_MAP.md`, `CLAIM_POLICY.md`, and `NOVELTY_TARGETS.md`.

Do not treat an EPS attempt as the theorem contract. Failed derivations normally trigger another EPS branch under the same DIC. Escalate only when the surviving result materially changes the publication objective or frozen architecture.

`reports/` should preserve the concise Theory decision plus key raw derivation/audit outputs in minimally transformed form where useful.
