# ULTRA.md — Machine Summary for Ultra Execution

Ultra is the highest workflow-governance level. Use for destructive migration, private/restricted
data, high-stakes science, locked paper evidence, release/submission or expensive external actions.

Mandatory additions:

- exact authority matrix and approval;
- proven rollback before mutation;
- immutable input/config/run identities;
- resource qualification before scale;
- backend/evidence separation;
- failure retention;
- Verifier-owned scientific/destructive/release gates;
- expected revision/stale-write controls;
- claim register and release authority separation;
- independent verification and re-verification after bounded repairs.

Ultra does not require every prompt to use the strongest model or full test suite. Route economical
Workers where checks are deterministic; escalate models and tests at high-consequence boundaries.
See `guides/GUIDE_ULTRA.md` for the full manual.
